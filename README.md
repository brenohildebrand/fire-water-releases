# Fire and Water

A two-player co-op platformer for macOS. Fire walks through lava, Water walks through water, and you need each other to reach the doors. Play on one keyboard or online together.

## Install

Open **Terminal** and paste:

```bash
curl -fsSL https://github.com/brenohildebrand/fire-water-releases/releases/latest/download/install.sh | bash
```

Or download `Fire-and-Water-mac.zip` from the [latest release](https://github.com/brenohildebrand/fire-water-releases/releases/latest), unzip it, and move **Fire and Water** into Applications. On the first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.

Runs on Apple Silicon and Intel Macs (macOS 11 or newer).

## Updates

The game updates itself automatically. It checks when it starts and every few minutes while you're in the menu. Every update is signed, and the game only installs builds signed by the developer.
